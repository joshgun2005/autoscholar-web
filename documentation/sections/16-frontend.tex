\chapter{Frontend Architecture}
\label{ch:frontend}

\section{Overview}
\label{sec:frontend:overview}

The \autoscholar frontend is a React 18.3 single-page application built with Vite 5, TailwindCSS 3, and TanStack React Query.
It provides three primary interfaces: (1) a conversational research interface for interactive analysis, (2) a public showcase of shared research reports, and (3) an administrative dashboard for pipeline management.

\subsection{Context Providers}

The app wraps all routes in a provider chain:

\begin{enumerate}
  \item \texttt{ErrorBoundary} --- Catches React rendering errors.
  \item \texttt{QueryClientProvider} --- TanStack React Query with 5-minute stale time, 30-minute GC.
  \item \texttt{ThemeProvider} --- Dark/light theme management.
  \item \texttt{TooltipProvider} --- Shared tooltip configuration.
  \item \texttt{ActiveSessionProvider} --- Global chat state management.
\end{enumerate}

\begin{itemize}
  \item Header with logo, navigation buttons (Repository, Journal, Live Paper, Docs), and session history drawer.
  \item Empty state with \texttt{ResearchForm} showing categorized research prompts and ``surprise paper'' button.

\subsection{Streaming Answer (\file{components/streaming-answer.tsx})}

The core rendering component (446 lines) for AI-generated content:

\begin{itemize}
  \item Uses \pkg{react-markdown} with \pkg{remark-gfm} and extensive custom component overrides.
  \item Content sanitization: strips leaked XML function call blocks, raw HTML tags, normalizes whitespace.
  \item Figure resolution: supports \texttt{fig://} protocol, markdown images, and figure registry lookups.
  \item Auto-scrolls during streaming with a blinking cursor indicator.
  \item Download link handling via blob URLs.
  \item Source display in a verified-badge grid.
  \item Code block syntax highlighting.
\end{itemize}

\begin{itemize}

  \begin{itemize}

\begin{itemize}

\section{State Management}
\label{sec:frontend:state}

\subsection{Chat Session Hook (\file{hooks/useChatSession.ts})}

The central state management hook (344 lines) manages $\sim$20 pieces of state:

\begin{itemize}
  \item Session ID (persisted to \texttt{sessionStorage}).
  \item Conversation history (array of Q\&A pairs).
  \item Streaming answer and loading state.
  \item Sources, search queries, and tool results.
  \item Agent steps with status tracking.
  \item Python code entries and figure batches.
  \item Monte Carlo and options pricing results.
  \item Figure registries (URL and base64 maps).
  \item Author profile (from \texttt{localStorage}).
\end{itemize}

Key operations:
\begin{description}
  \item[\func{handleSearch}] Initiates a new query, manages streaming state, and accumulates results.
  \item[\func{handleRetry}] Re-submits the last query.
  \item[\func{handleNewConversation}] Resets all state for a fresh session.
  \item[\func{handleLoadSession}] Loads a previous session from the API.
\end{description}

\subsection{Chat Mutation Hook (\file{hooks/useChatMutation.ts})}

SSE streaming implementation (165 lines):

\begin{enumerate}
  \item Sends POST to \texttt{/api/chat} with query and conversation history.
  \item Reads response body as a stream.
  \item Parses SSE \texttt{data:} lines into typed events.
  \item Forwards each chunk to the \texttt{onChunk} callback.
  \item Supports \texttt{AbortController}-based cancellation.
  \item Handles 401 by reloading the page.
\end{enumerate}

\subsection{Analytics Hook (\file{hooks/useAnalytics.ts})}

Platform telemetry (94 lines):

\begin{itemize}
  \item Heartbeat POST every 30 seconds during active generation.
  \item Real-time stats polling at configurable intervals (default 10s).
  \item Auto-generated session IDs persisted in \texttt{sessionStorage}.
\end{itemize}

\section{Document Export}
\label{sec:frontend:export}

\subsection{Server-Side Export}

Three export buttons trigger server-side generation:

\begin{itemize}
  \item \textbf{PDF:} POST to \texttt{/api/generate-pdf} --- Puppeteer renders HTML to PDF.
  \item \textbf{DOCX:} POST to \texttt{/api/generate-docx} --- Pandoc converts markdown.
  \item \textbf{HTML:} POST to \texttt{/api/generate-html} --- Self-contained HTML with KaTeX.
\end{itemize}

\subsection{Client-Side Export}

\begin{itemize}
  \item \textbf{Markdown:} Client-side blob download (no server call).
  \item \textbf{Advanced PDF:} \file{pdfGenerator.ts} (539 lines) uses jsPDF + html2canvas for element capture with AutoScholar-branded headers, pagination, and table formatting.
\end{itemize}

\section{Configuration}
\label{sec:frontend:config}

\file{config.ts} (58 lines) defines:

\begin{itemize}
  \item \textbf{Base URL:} Production (\texttt{https://autoscholar.ai}) vs development (\texttt{localhost:3001}).
  \item \textbf{App metadata:} Name ``AutoScholar'', version ``3.0.0''.
  \item \textbf{Feature flags:} \texttt{pythonCustomCode}, \texttt{pdfDownload}, \texttt{sharing}, \texttt{exportData}, \texttt{multiSource}.
  \item \textbf{Limits:} \texttt{maxToolsPerBatch}: 5, \texttt{maxPdfChars}: 3M, \texttt{maxQueryLength}: 10K.
\end{itemize}

\section{Build and Development}
\label{sec:frontend:build}

\subsection{Development}

\begin{itemize}
  \item Vite dev server with React HMR plugin.
  \item PostCSS with TailwindCSS and Autoprefixer.
  \item Path aliases: \texttt{@} $\to$ \texttt{client/src}, \texttt{@shared} $\to$ \texttt{shared}.
  \item Relaxed filesystem access for monorepo structure.
\end{itemize}

\subsection{Production Build}

\begin{itemize}
  \item \texttt{vite build} outputs to \texttt{dist/public/}.
  \item Static files served by Express in production mode.
  \item SEO meta tags in \file{index.html} (Open Graph, Twitter Cards).
  \item Google Fonts preconnect for Inter, Space Grotesk, Playfair Display, Libre Baskerville, EB Garamond, JetBrains Mono.
\end{itemize}
